# SatyaCheck — Real Hinglish Fake-News Detection

A production-style academic prototype for Hindi, English and Hinglish misinformation screening.

## What makes this version different

- Word + character TF-IDF for Roman-Hindi spelling variation.
- Calibrated Linear SVM with an uncertainty/abstention threshold.
- Leakage-aware split support using `split`, `group_id`, `event_id` or `story_id` when available.
- Flask web app and JSON API.
- `/health` endpoint for deployment monitoring.
- Dataset preparation script for HinFakeNews-style spreadsheets.
- Optional MuRIL fine-tuning path for GPU/Google Colab.

## Important: do not fake the accuracy

The included demo data is for UI testing only. Do not claim 90%+ accuracy from it. Train on a real, labelled, licence-compliant dataset and report the held-out test metrics generated by the training script.

## Windows setup

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Real dataset

Put a labelled CSV at:

```text
data/hinglish_news.csv
```

Required:

```text
title,text,label
```

Then:

```powershell
python scripts/validate_dataset.py
python model/train_hinglish.py
python app.py
```

Open `http://127.0.0.1:5000`.

## Preparing HinFakeNews

Download the dataset from an authorized source, save it as:

```text
data/raw/HinFakeNews-V1.xlsx
```

Then:

```powershell
python scripts/prepare_hinfakenews.py
```

Review the generated file before training. If you have a native-Hindi file, create the Hinglish/Romanized version with a transliteration pipeline and retain the original source text for auditability.

## Advanced model

`model/train_muril.py` fine-tunes `google/muril-base-cased` on GPU. MuRIL is pretrained on 17 Indian languages and transliterated counterparts, making it a strong candidate for Romanized Hindi/code-mixed text.

## Deployment

Build command:

```text
pip install -r requirements.txt
```

Start command:

```text
gunicorn app:app
```

The trained model files are intentionally gitignored. For deployment, either package the trained model through your platform's artifact/storage mechanism or adjust `.gitignore` if the binary size/licensing policy allows it.

## Research recommendation

Use the TF-IDF+SVM system as a fast baseline and MuRIL as the advanced model. Report accuracy, precision, recall, macro-F1, confusion matrix, dataset composition and split methodology. Keep a separate recent holdout set for the final evaluation.
